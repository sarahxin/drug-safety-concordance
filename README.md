# Drug Safety Concordance
This archive contains Python scripts for harmonizing, analyzing, and comparing concordance between human and animal drug safety data

Identical_term_concordance.py: Concordance using identical AE terms.
  
NonIdentical_term_concordance.py: Concordance allowing nonidentical AE term mapping.
  
SOC_Concordance.py: SOC-level concordance calculations.

Data Availability
Raw data is not included due to licensing restrictions.
Scripts require input files in the formats described in the code. 

You can run the workflows by retrieving and process your own data in the same formats, or using the supplied dummy files for testing.

Requirements
  
Python 3.x
  
pandas, numpy, scipy, tqdm, statsmodels, scikit-learn, matplotlib
